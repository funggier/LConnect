- raw `netstat -ano -p tcp`: approximately **257,870 chars / 3,343 lines**

### 2. Live UIA Unicode result serialization

Disposable Chrome physical qualification showed Thai/Unicode content was reaching the page but UIA worker return values were corrupted as `?`/replacement characters under Windows PowerShell 5.1 stdout.

Isolation:
- base64 UTF-8 payload decode preserved exact codepoints
- `ValuePattern.SetValue` preserved exact codepoints inside worker
- native Windows title observation showed correct Thai/Unicode page state
- corruption was isolated to PowerShell worker stdout serialization

Repair:
- `[Console]::OutputEncoding` set to UTF-8
- `$OutputEncoding` set to UTF-8
